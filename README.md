# IoT Skill Trainer — ESP32

## วิธีเปิดด้วย VS Code
1. แตกไฟล์ ZIP
2. เปิด VS Code
3. เลือก File > Open Folder แล้วเลือกโฟลเดอร์ `iot_competition_practice`
4. เปิด `index.html`
5. แนะนำติดตั้งส่วนขยาย **Live Server** ใน VS Code แล้วคลิกขวา `index.html` > Open with Live Server

## เนื้อหาในเว็บ
- แผนฝึก 14 แผน พร้อมช่องจดบันทึกและปุ่มบันทึกแต่ละแผน (เก็บใน localStorage ของเบราว์เซอร์ กลับมาเปิดแล้วข้อมูลเดิมยังอยู่)
- ตารางคำสั่ง Arduino พื้นฐาน
- บทเรียน LED, RGB LED, Ultrasonic และ LCD I2C
- โค้ดตัวอย่าง ESP32
- โจทย์ปฏิบัติจำลอง 3 ข้อ พร้อมแนวคิดเฉลย
- ข้อสอบทฤษฎี 10 ข้อ ตรวจคะแนนและอธิบาย
- Checklist ก่อนส่งงาน

## หมายเหตุด้านฮาร์ดแวร์
- ตัวอย่าง RGB ใช้แบบ Common Cathode; Common Anode ต้องกลับตรรกะ
- HC-SR04 Echo มักเป็น 5V ต้องใช้วงจรแบ่งแรงดันก่อนเข้า ESP32
- LCD I2C ตัวอย่างใช้ address 0x27 และ SDA=21/SCL=22; ตรวจสอบโมดูลจริงก่อนใช้งาน
- ตรวจสอบแรงดัน VCC และระดับสัญญาณ I2C ของจอ LCD ให้เข้ากับ ESP32
- โค้ดเป็นตัวอย่างเพื่อฝึก ควรทดสอบกับอุปกรณ์จริงและปรับ pin ตามชุดแข่งขัน

## การนำขึ้น GitHub Pages
1. สร้าง repository แล้วอัปโหลดไฟล์ทั้ง 4 ไฟล์ (`index.html`, `style.css`, `script.js`, `README.md`) ไว้ที่ root
2. ไปที่ Settings > Pages > Source เลือก branch `main` โฟลเดอร์ `/ (root)` แล้วกด Save
3. เปิดลิงก์ `https://<username>.github.io/<repo>/`

หมายเหตุ: ข้อมูลที่บันทึกเก็บในเบราว์เซอร์ของแต่ละเครื่อง ไม่ได้ส่งขึ้นเซิร์ฟเวอร์ ถ้าเปลี่ยนเครื่อง/เบราว์เซอร์ หรือล้างข้อมูลเว็บไซต์ ข้อมูลจะหาย
